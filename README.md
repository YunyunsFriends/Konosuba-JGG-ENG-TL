## Konosuba Judgment on this Greedy Game Prologue English Patch for PC
This patch adds a full English Translation for PC.
###
### PC Patch Features
- All 25,569 lines have received a base translation from H. Berry, and a few files from Kiril K.
- The game now runs using Vulkan instead of DirectX.
- Updated video codec to render high quality switch OP and ED with built-in subtitle support.
- The game's window size can be adjusted or snapped.
- Built in installation error explanations.
- Discord Rich Presence.
- Swimsuit DLC enabled in game.
- Trophy support.
## Where to buy the game

## FAQ
### Do you plan to patch the Switch, Vita, and PS4 versions?
Those versions of the game have various differences that we would need to make adjustments for due to differences in textures and the resolution on Vita.
### Do I need the game?
Yes, the files in releases are what's strictly needed for the patch. **If you try to run the executable in the patch files without overwriting the game files you will get an error.**
### Can I play this on a Steam Deck?
Steam Deck support is in testing. The game is bundled with required dlls.
